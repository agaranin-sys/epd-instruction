Документы и триггеры для их формирования

Наименование документа Триггер для его формирования
Черновик Поручения Экспедитора (ЭПЭ) для клиента Черновик Т1 Формируется автоматически, когда заявка перешла на статус «подтверждена»
Чистовик Поручения Экспедитора (ЭПЭ) для клиента Чистовик Т2 Подпись Т2 ЭПЭ происходит автоматически после того, как клиент подпишет свой титул Т1 ЭПЭ
Чистовик Экспедиторской расписки для клиента (ЭЭР) Чистовик ЭПЭ Т1 подписан клиентом; При плече «забор» в поездке есть факт прибытия водителя на загрузку; При самопривозе силами клиента есть спланированное следующее плечо
Чистовик Транспортной накладной (ЭТрН) Чистовик Т1 Формируется в момент появления данных в поездке об убытии водителя с загрузки
Черновик Транспортной накладной (ЭТрН) Черновик Т1 Формируется при двойной экспедиции, т.е. перевозчик на портале внёс информацию, что водитель не в штате, и указал реального перевозчика, и в момент появления данных в поездке об убытии водителя с загрузки
Чистовик Заказа-Заявки (ЭЗЗ) для перевозчика Чистовик Т1 Формируется в момент появления данных в поездке по водителю
Чистовик Поручения Экспедитору (ЭПЭ) экспедитору 2 Чистовик Т1 Формируется при двойной экспедиции, т.е. перевозчик на портале внёс информацию, что водитель не в штате, и указал реального перевозчика
Черновик Экспедиторской расписки (ЭЭР) для Экспедитора 2 Черновик Формируется при двойной экспедиции, т.е. перевозчик на портале внёс информацию, что водитель не в штате, и указал реального перевозчика, и по данной поездке есть подписанное Поручение экспедитору

Как проверить формирование документов

3 Чистовик Транспортной накладной (ЭТрН) Титул 1
ТМСХ: Зайти по поездке в раздел «Документы»
4 Черновик Транспортной накладной (ЭТрН) Титул 1
ТМСХ: Зайти по поездке в раздел «Документы»
5 Чистовик Заказа-Заявки (ЭЗЗ) для перевозчика
ТМСХ: Зайти по поездке в раздел «Документы»
6 Чистовик Поручения Экспедитору (ЭПЭ) экспедитору 2
ТМСХ: Зайти по поездке в раздел «Документы»
7 Черновик Экспедиторской расписки (ЭЭР) для Экспедитора 2
ТМСХ: Зайти по поездке в раздел «Документы»
